# Билеты с QR — инструкция по запуску

Проект: Next.js сайт с оплатой Stripe, автоматической генерацией
именного QR-билета, отправкой на почту, сканером на входе и
дашбордом с аналитикой.

Ниже — пошагово, с нуля. Нужно создать 3 бесплатных аккаунта
(Supabase, Resend) плюс твой Stripe, и один аккаунт для хостинга
(Vercel). Везде даю прямые ссылки.

---

## Шаг 1. Supabase (база данных)

1. Зайди на https://supabase.com → Sign up → создай проект (Free tier).
2. Дождись, пока проект поднимется (1-2 минуты).
3. Слева зайди в **SQL Editor** → New query → скопируй туда содержимое
   файла `supabase-schema.sql` из этого проекта → Run.
   Это создаст таблицу `tickets`.
4. Зайди в **Project Settings → API**. Скопируй:
   - `Project URL` → это `SUPABASE_URL`
   - `service_role` key (не `anon`!) → это `SUPABASE_SERVICE_ROLE_KEY`

   ⚠️ `service_role` ключ даёт полный доступ к базе — никогда не
   публикуй его и не вставляй в код фронтенда. Он используется только
   на сервере (уже так настроено в проекте).

## Шаг 2. Stripe (оплата)

1. У тебя уже есть аккаунт — зайди на https://dashboard.stripe.com
2. Пока тестируем — оставайся в **Test mode** (переключатель вверху
   справа). Когда всё заработает — переключишься на Live mode и
   повторишь шаги 2-3 с боевыми ключами.
3. **Developers → API keys** → скопируй `Secret key` → это
   `STRIPE_SECRET_KEY`.
4. Настройку `STRIPE_WEBHOOK_SECRET` сделаем в Шаге 5 (webhook нужно
   создавать уже после того, как сайт задеплоен и у него есть адрес).

## Шаг 3. Resend (отправка писем с QR)

1. Зайди на https://resend.com → Sign up (бесплатный тариф хватит на
   старте — 3000 писем в месяц).
2. **API Keys → Create API Key** → скопируй → это `RESEND_API_KEY`.
3. Чтобы письма не попадали в спам, нужно подтвердить свой домен:
   **Domains → Add Domain** → впишет несколько DNS-записей, которые
   нужно добавить у регистратора домена. Это может занять до суток на
   распространение DNS.
   - Если домена пока нет — можно временно использовать тестовый адрес
     `onboarding@resend.dev` в качестве `EMAIL_FROM` (Resend даёт его
     из коробки), но письма будут уходить только на твою же почту,
     привязанную к аккаунту Resend. Для реальных продаж домен
     понадобится.

## Шаг 4. Локальный запуск (проверить, что всё работает)

```bash
npm install
cp .env.example .env.local
```

Заполни `.env.local` значениями из шагов 1-3. `ADMIN_PASSWORD` и
`ADMIN_SESSION_SECRET` — придумай сама, это пароль для входа в
`/admin` и `/scan`.

```bash
npm run dev
```

Открой http://localhost:3000 — должен появиться сайт.

Оплата локально работать не будет (Stripe должен достучаться до
твоего webhook, а localhost снаружи не виден) — для этого шага удобнее
сразу задеплоить (Шаг 5) и тестировать уже на реальном адресе.

## Шаг 5. Деплой на Vercel

1. Залей проект на GitHub (можно через веб-интерфейс — просто
   загрузить файлы в новый репозиторий, drag-and-drop работает).
2. Зайди на https://vercel.com → Sign up (можно через GitHub) →
   **Add New → Project** → выбери свой репозиторий.
3. В настройках проекта **Environment Variables** добавь все
   переменные из `.env.local`, кроме `SITE_URL` (не обязательна).
4. Deploy. Через минуту получишь адрес вида
   `https://твой-проект.vercel.app`.

## Шаг 6. Подключить Stripe webhook (важно!)

Без этого шага деньги будут списываться, а билеты — не создаваться.

1. В Stripe: **Developers → Webhooks → Add endpoint**.
2. Endpoint URL: `https://твой-проект.vercel.app/api/webhook`
3. Events to send: выбери `checkout.session.completed`.
4. Add endpoint → открой созданный webhook → **Signing secret** →
   скопируй (начинается на `whsec_...`) → это `STRIPE_WEBHOOK_SECRET`.
5. Вернись в Vercel → Settings → Environment Variables → добавь/обнови
   `STRIPE_WEBHOOK_SECRET` → Redeploy (Deployments → ⋯ → Redeploy).

## Шаг 7. Проверка полного цикла

1. Открой свой сайт, нажми «Купить билет».
2. Введи тестовую карту Stripe: `4242 4242 4242 4242`, любая future
   дата, любой CVC.
3. После оплаты проверь почту, куда указывал при оплате — должен
   прийти QR.
4. Зайди на `https://твой-проект.vercel.app/scan` (спросит пароль —
   это `ADMIN_PASSWORD`), наведи камеру на QR из письма — должно
   показать «Проход разрешён».
5. Отсканируй тот же QR ещё раз — должно показать «Билет уже
   использован».
6. Зайди на `/admin` — увидишь список билетов и графики.

## Как поменять фото в галерее «Фото с прошлых тусовок»

Сейчас там 8 заглушек-абстракций (я их сгенерировал, чтобы не
использовать чужие фото без разрешения). Чтобы поставить свои:

1. Положи фото в папку `public/gallery/` (любые имена файлов,
   желательно квадратные, от 500×500px).
2. Открой `app/PartyGallery.tsx` и поменяй пути в списке `photos` на
   имена своих файлов.
3. `git push` — Vercel передеплоит сайт автоматически.

## Как поменять цену, название мероприятия

Всё в переменных окружения — `EVENT_NAME`, `TICKET_PRICE_CENTS`
(в центах, 2500 = €25.00), `TICKET_CURRENCY`. Поменяй в Vercel →
Environment Variables → Redeploy.

## Ограничения текущей версии (MVP)

- Один билет = одна покупка (нельзя купить сразу 3 билета одной
  оплатой). Если понадобится — расширим.
- Один тип билета по фиксированной цене (без категорий VIP/обычный).
- Админ-доступ — один общий пароль на организатора, без отдельных
  аккаунтов для нескольких человек на входе.
